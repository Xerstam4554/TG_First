# Техническое задание для Telegram-бота (стоматология)

## Общее описание
Разработать Telegram-бота для онлайн-записи в стоматологию с использованием базы данных SQLite.

## Функциональные требования

### 1. Запуск бота
- Пользователь запускает бота командой `/start`

### 2. Выбор услуги
- Бот приветствует пользователя и показывает 3 кнопки: `Осмотр`, `Чистка`, `Лечение`

### 3. Выбор даты
- После выбора услуги бот показывает 2 кнопки: `Сегодня`, `Завтра`

### 4. Выбор времени (с проверкой БД)
- После выбора даты бот обращается к таблице `slots` в БД
- Начальные слоты: `10:00`, `11:30`, `13:00`
- Бот показывает ТОЛЬКО свободные слоты (поле `is_free = True`)
- Если слот занят — не отображается

### 5. Выбор слота
- Пользователь выбирает свободное время

### 6. Ввод имени
- Бот запрашивает имя → пользователь вводит текст

### 7. Ввод телефона
- Бот запрашивает номер телефона → пользователь вводит текст

### 8. Сохранение в БД
- Сохранить запись в таблицу `appointments`:
  - услуга
  - дата
  - время
  - имя
  - телефон
  - `telegram_id` пользователя
  - статус `active`
- Обновить `slots`: `is_free = False` для выбранных даты и времени

### 9. Уведомление администратора
- Отправить сообщение фиксированному Telegram ID (прописан в коде)
- Формат сообщения:
- Новая запись
Услуга: [название]
Дата: [дата] [время]
Имя: [имя]
Телефон: [номер]
- 
### 10. Ответ пользователю
- Бот отправляет: `Записано! Спасибо`

### 11. Сброс состояния
- Бот возвращается в начальное состояние (готов к новой записи)

## Обработка конфликтов
- Если выбранный слот уже занят (`is_free = False` в момент записи):
  - Бот сообщает: `Это время уже занято, выберите другое`
  - Показывает актуальный список свободных слотов (повторный запрос к БД)

## Структура базы данных (SQLite)

### Таблица `slots`
| Поле    | Тип      | Описание                    |
|---------|----------|-----------------------------|
| id      | INTEGER  | PRIMARY KEY AUTOINCREMENT   |
| date    | TEXT     | дата в формате YYYY-MM-DD    |
| time    | TEXT     | время "10:00", "11:30", "13:00" |
| is_free | INTEGER  | 1 = свободно, 0 = занято     |

### Таблица `appointments`
| Поле         | Тип      | Описание                          |
|--------------|----------|-----------------------------------|
| id           | INTEGER  | PRIMARY KEY AUTOINCREMENT         |
| user_id      | INTEGER  | telegram_id пользователя           |
| service      | TEXT     | "Осмотр", "Чистка", "Лечение"      |
| date         | TEXT     | YYYY-MM-DD                        |
| time         | TEXT     | "10:00", "11:30", "13:00"         |
| name         | TEXT     | имя пользователя                   |
| phone        | TEXT     | номер телефона                     |
| status       | TEXT     | "active"                          |

## Инициализация БД
- При первом запуске бота (или отдельным скриптом) заполнить `slots`:
  - Для дат "сегодня" и "завтра"
  - Для каждого времени: `10:00`, `11:30`, `13:00`
  - Поле `is_free = 1` (свободно)

## Исключения (НЕ реализуются)
- Напоминания
- Отмена записи
- Выбор врача
- Календарь на месяц
- Оплата
